# Fresh

Fresh is a personal native iOS app that helps people prioritize food before it is forgotten. It uses transparent, deterministic freshness estimates and remains careful not to present those estimates as food-safety guarantees.

The app is currently at G00: agentic project foundation and product/UI specification. Application implementation begins after the written design is approved.

## Current Git policy

G00 will form the first verified `main` baseline. Later work integrates through `dev`, with one `feature/gXX-name` branch per roadmap goal. Agent-created commits, pushes, and pull requests wait until the complete goal passes verification and a fresh reviewer reports no material findings.
