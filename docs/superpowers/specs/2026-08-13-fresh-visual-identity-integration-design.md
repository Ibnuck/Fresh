## Outcome summary

Fresh preserves the approved Sprout & Slice icon concept and screen-style catalog in stable repository locations, records which visual rules are authoritative, and explicitly prevents mismatched legacy layers from being treated as final artwork.

## Decisions

### Concept fidelity

`Design/AppIcon/Fresh_App_Icon_Concept_02.png` is the authoritative visual reference. The previously supplied `01_back`, `02_middle`, and `03_front` assets differ from that concept and are rejected as production masters.

The replacement deliverable is one `1024 × 1024` transparent PNG containing the complete foreground symbol. It must replicate the concept as closely as possible in form, relative scale, overlap, color, and style. It must not contain the sage background, iOS mask, rounded-square plate, presentation text, or mockup effects.

### Icon Composer ownership

The owner will choose the background colors in Apple Icon Composer. The final foreground therefore remains a single transparent layer. Runtime integration is deferred until the replacement artwork is generated, reviewed, and approved.

This goal does not create or claim a final `Fresh/AppIcon.icon`, and does not modify the asset catalog.

### Screen-catalog boundary

`Design/UIConcepts/fresh_ui_visual_direction.png` is a visual-direction proposal. It contributes palette, organic illustration style, calm spacing, and hierarchy, but cannot override product scope, navigation, input behavior, safety language, or the official screen specs.

Search remains available on `My Food` as already specified. Category is generated by Fresh, while storage location, condition, and package status are free text. Ripeness may be part of condition and is not a separate field.

## Acceptance criteria

- Both visual reference images exist and their dimensions can be inspected.
- The icon specs consistently require one transparent foreground matching the concept.
- No document treats the rejected three-layer artwork or a nonexistent `.icon` file as final.
- The UI reconciliation preserves approved MVP navigation, fields, search, and safety boundaries.
- Another chat can find the references from `Design/README.md` without reading the original conversation.
- The current diff contains no runtime asset or Swift code change.
- A context-clean reviewer returns `Verdict: No material findings.`

After the owner commits and pushes this reference milestone, provide an ordered image-generation prompt. The first prompt generates only the exact transparent icon foreground. After the result is reviewed and approved, a separate goal integrates it in Icon Composer and verifies the app build.
