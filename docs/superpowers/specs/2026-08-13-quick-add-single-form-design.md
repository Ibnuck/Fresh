# Quick Add Single-Form Design

## Status

- Date: 2026-08-13
- Status: approved by owner
- Scope: Quick Add visual and interaction flow
- Replaces: the four-step Quick Add presentation; the old generated bitmap remains review history

## Outcome

The user can enter everything they know about one food in a single scrollable native sheet, review Fresh's interpretation, and save only after explicit confirmation. The form remains useful with only a food name and never invents missing context.

## Chosen approach

Use one large-detent `Tambah bahan` sheet containing a vertically scrollable form and a keyboard-safe bottom action `Tinjau estimasi`. This is preferable to four separate steps because the core input set is small, most fields are optional, and the user can understand the total effort immediately.

The sheet contains:

1. `Nama bahan` — required free text.
2. `Tambah foto` — optional and decorative; it is not a required analysis input.
3. `Lokasi penyimpanan` — optional free text.
4. `Kondisi bahan` — optional free text; ripeness is included only when the user writes it naturally.
5. `Status kemasan` — optional free text.
6. Reference date — `Tanggal pada kemasan`, `Tanggal dibeli`, or `Tidak ada tanggal`; a native date picker appears when a dated option is selected.
7. `Detail lainnya` — collapsed by default; quantity and notes only.

The short helper `Isi yang kamu tahu saja. Informasi yang kosong akan ditandai belum diketahui.` makes the optional behavior explicit. `Nama bahan` is the only required input.

## Information ownership

- Preserve every user-entered string exactly.
- Category is generated by Fresh through local matching and optional on-device interpretation; it is not a form field.
- Fresh may normalize only details actually stated by the user.
- Missing storage, condition, package status, ripeness, or date remains `unknown`.
- Foundation Model output never supplies shelf-life facts or food-safety verdicts.
- Deterministic Fresh rules produce the freshness estimate.

## Navigation and persistence

- Entry: global `Tambah`, Today empty CTA, or onboarding completion.
- `Batal` with an unchanged form dismisses; a modified draft asks `Buang draft?` with `Lanjut mengisi` and `Buang`.
- `Tinjau estimasi` is disabled while the trimmed name is empty.
- Tapping `Tinjau estimasi` preserves the draft and opens Estimate Review; it does not save.
- `Simpan bahan` on Estimate Review is the first persistence attempt.
- Back from Estimate Review restores this form and its values.

## Adaptive and failure behavior

- Content scrolls independently of the safe-area action dock.
- Focused fields and the primary action stay above the keyboard.
- Dynamic Type stacks and grows controls rather than shrinking text.
- Interpretation unavailable does not block review; raw input remains intact and unresolved values remain unknown.
- Validation appears next to `Nama bahan`; a persistence error belongs to Estimate Review and retains the draft.

## Scope

No category picker, separate ripeness field, storage/condition/package presets, barcode/OCR, AI chat, nutrition, price/store, automatic save, or safety guarantee.
