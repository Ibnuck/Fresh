# Fresh Review Packet Template

```markdown
# Review packet — Gxx Goal name

## Outcome summary
What the user can do after this goal.

## Contract
- Spec: path
- Acceptance criteria: concise list or path

## Scope
- Changed files: paths
- Relevant neighboring files: paths
- Out of scope: explicit exclusions

## Verification supplied by implementation agent
- Build command and result
- Test command and result
- Simulator/manual checks and result

## Reviewer constraints
- Read-only; do not edit, stage, commit, or push.
- Use `$fresh-code-review`.
- Return evidence-based P0–P3 findings or `Verdict: No material findings.`
```
